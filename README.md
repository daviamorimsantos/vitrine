# VITRINE - Projeto 4 do portfólio

Catálogo digital demonstrativo focado em conversão pelo WhatsApp.

## Recursos
- Busca de produtos
- Filtro por categoria
- Cards com preço e descrição
- Modal de produto
- Seleção de quantidade
- Mensagem automática no WhatsApp
- Layout responsivo
- Sem framework e sem dependências pagas

## Publicação
Envie `index.html`, `style.css` e `README.md` para um repositório GitHub e importe na Vercel.

## Personalização
Troque produtos, preços, fotos, nome da loja e o número `5517999999999` antes de usar com um cliente real.
